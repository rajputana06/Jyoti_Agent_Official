🤖 ABOUT JYOTI AGENT

Jyoti Agent is the flagship multi‑modal AI assistant of Rajputana Jyoti System. Key capabilities:
• Offline‑first & Wake Word support (planned updates) – enables local voice activation without continuous internet.
• Cloudflare Edge Network for ultra‑low latency, DDoS protection, and secure data routing.
• Zero‑server storage (Ephemeral Processing): RJS does NOT permanently store any user chat history, voice recordings, or uploaded files on its own servers. Data is processed in‑memory (RAM) and instantly deleted after the response is delivered.
• Multi‑modal input: text, voice, images, PDFs, videos – processed via third‑party LLMs (Bhashini, Groq, Mistral, OpenRouter, etc.).
• Smart Memory via Google Drive (drive.file scope): with user permission, Jyoti Agent stores contextual memory only in the user’s personal Google Drive – RJS never accesses any other files.
• Privacy‑First: microphone, camera, and location permissions are used only for real‑time interactions and environmental data (weather/AQI) – no tracking, no permanent retention.

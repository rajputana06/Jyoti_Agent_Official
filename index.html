ABOUT JYOTI AGENT • MULTI‑MODAL AI

Jyoti Agent is the flagship multi‑modal AI assistant of Rajputana Jyoti System. Key capabilities:

  • 📴 Offline‑first & Wake Word support (planned) – local voice activation without continuous internet.
  • 🌐 Cloudflare Edge Network for ultra-low latency, DDoS protection, and secure routing.
  • 🧠 Zero‑server storage (Ephemeral Processing): RJS does NOT permanently store any user chat history, voice recordings, or uploaded files. Data is processed in‑memory and deleted after response delivery.
  • 🎤📄 Multi‑modal input: text, voice, images, PDFs, videos via third‑party LLMs (Bhashini, Groq, Mistral, etc.).
  • ☁️ Smart Memory via Google Drive (drive.file scope): with user permission, Jyoti Agent stores contextual memory only in the user’s personal Google Drive – RJS never accesses any other files.
  • 🔒 Privacy‑First: microphone, camera, and location permissions used only for real‑time interactions – no tracking, no permanent retention.
